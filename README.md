# MAKTUB — Atelier de Noivas

Frontend prototype for the MAKTUB bridal atelier in Luanda, Angola. Built with Next.js App Router, TypeScript and CSS, using the supplied MAKTUB logo and promotional poster.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. The administrative prototype is available at `/admin`.

Product settings and lightweight records are stored in `localStorage`; uploaded product images are stored in IndexedDB. This phase has no backend, payment processing or cross-device synchronization.
